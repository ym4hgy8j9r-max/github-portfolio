# Development Prompt Log

I used an AI assistant as a support tool while planning and developing the Cybersecurity Study Assistant. The prompts below show the specific areas where I requested help. I reviewed the suggestions and used them to guide my own implementation and revisions.

1. **Planning:** "Help me plan a small Python command-line study assistant for cybersecurity topics. Outline a simple workflow and the files I will need."
   - Helped me organize the project's purpose and basic structure.

2. **Implementation guidance:** "Show me how to send a user's question to an AI API from Python while reading the API key from an environment variable."
   - Helped me understand the API request and safer key handling.

3. **Error handling:** "What errors should a small Python command-line API client handle, and how can I display useful messages?"
   - Helped me identify missing-key, HTTP, and connection errors to handle.

4. **Code review:** "Review this Python program for readability and point out issues I should test."
   - Helped me review the implementation and prepare a testing checklist.

5. **Safety review:** "Suggest a concise system instruction that keeps a cybersecurity study assistant focused on education and authorized lab work."
   - Helped me add an appropriate scope for the assistant's responses.

The AI tool provided suggestions and development assistance; it did not independently design, verify, or submit the project. I am responsible for reviewing the code, running the tests, and understanding the final program.
